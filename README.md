📝 **Blog Web Application**

A full-stack blogging platform where users can create, edit, delete, and manage blog posts through a clean and responsive interface. The application provides an intuitive writing experience while allowing users to browse published blogs seamlessly.

## 🌐 Live Demo
🔗 **[View Blog Application](https://blog-hcnj.onrender.com/)**

**Features**
Create, edit, and delete blog posts (CRUD operations)
Responsive and user-friendly interface
Dynamic rendering using EJS templates
RESTful routing
Express.js backend with Node.js
Clean UI built with HTML, CSS, and JavaScript


**Tech Stack**
Frontend: HTML, CSS, JavaScript, EJS
Backend: Node.js, Express.js
Database: PostgreSQL
Deployment: Render
